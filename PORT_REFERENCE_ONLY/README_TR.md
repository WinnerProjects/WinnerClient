# Donut Client özellik kaynakları — referans

Bu klasör, SeedESP (Donut'taki BlockESP seed tahmini) ve SoundNotifier/Sound Detector portu için Donut Client kaynaklarını referans olarak içerir.

**ÖNEMLİ:** Bu klasör WinnerClient'ın `src/main/java` kaynak ağacına dahil DEĞİLDİR. Donut Client Mojang mappings kullanırken WinnerClient Yarn mappings kullanıyor. Dosyaları doğrudan ana kaynaklara kopyalamak derleme hataları üretir. Bu nedenle bu klasör güvenli biçimde ayrı tutuldu; henüz WinnerClient'a port edilmiş/çalışır modül olarak sunulmuyor.

- SeedESP: `src/client/java/dev/donut/client/blockesp/`
- SoundNotifier: `src/client/java/dev/donut/client/sound/`, `config/`, `gui/` ve `mixin/`
- Orijinal lisans: `LICENSE`

Port sırasında orijinal telif ve lisans bildirimleri korunmalıdır. Donut projesindeki farklı lisanslı bileşenlerin şartları da geçerlidir.
